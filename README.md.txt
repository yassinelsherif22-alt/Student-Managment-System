# 🎓 Student Management System (C++)

A console-based Student Management System developed using C++.  
This system allows students and admins to manage courses, registrations, and grades.

## 🚀 Features
- Student Sign In / Sign Up
- Course Registration
- View Registered Courses
- View Grades
- GPA Calculation
- Admin Panel:
  - Add Courses
  - Set Prerequisites
  - Manage Grades
- File Handling (Save & Load Data)

## 🛠️ Technologies Used
- C++
- STL (vector, map, queue)
- File Handling

## 📂 Files
- main.cpp → Main program file
- students.txt → Stores students data
- courses.txt → Stores courses data

## ▶️ How to Run
1. Open project in Visual Studio
2. Build the project
3. Run the program
